# gsap_portfolio
> A gsap based portfolio made in Next.js, React, Tailwind CSS, and GSAP.

[Demo](https://dlprd.com)

![preview gif/screenshot]

## Features
- Parallax Effect
- Shapeshifting
- Multiple z-index's for gallery effect

## Getting Started
### Prerequisites
- node.js 18+
- npm / yarn
- git
### Installation
#### Windows / Mac / Linux
```bash
git clone https://github.com/dlpcube/gsap_portfolio
cd gsap_portfolio
npm install
npm run main
```
